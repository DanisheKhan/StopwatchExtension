# Focus Flow ⏳

Focus Flow is a minimal, classic Chrome extension designed for deep work, uninterrupted flow states, and seamless time tracking. Built with timeless design principles inspired by Dieter Rams and modern high-performance tooling, Focus Flow helps you stay in the zone without cognitive clutter or micromanagement.

---

## ✨ What's New & Core Features

### 🏛️ Minimal Classic Design System
- **Balanced Proportions:** Refined 380px fixed-width popup with zero jitter or harsh browser scrollbars.
- **Obsidian & Emerald Palette:** Replaces eye-straining high-contrast neon greens with a calm, focused Emerald Sage (`#10B981`) and deep Obsidian slate background.
- **Tabular Monospace Typography:** Rock-solid numeric displays using tabular figures (`font-variant-numeric: tabular-nums`) so numbers never twitch or shift when ticking.
- **Tactile Micro-Interactions:** Subtle button presses, harmonic progress ring gradients, and breathing focus indicators.

### ⏱️ Dual Mode: Stopwatch & Pomodoro
- **Open-Ended Stopwatch:** Track uninterrupted deep work sessions and billable hours.
- **Pomodoro Sprint Timer:** 1-click switch to focused countdown sprints with quick preset chips (`15m`, `25m`, `45m`, `60m`).
- **Celebration Alert:** Automatic completion chime and notification when your sprint finishes.

### 🏷️ Focus Task & Tagging
- Direct "What are you focusing on?" input bar with quick tags: `Deep Work`, `Code`, `Design`, `Writing`, `Study`.
- Automatically associates every focus session with its respective tag for detailed analytics.

### 📋 Today's Chronological Log & Instant Export
- **Interval Timeline:** Review all focused intervals throughout the day with start time, end time, tag, and duration.
- **Copy Standup Summary:** 1-click copy formatted markdown summary ready to paste into Slack, Teams, Discord, or daily notes.
- **Export to CSV:** Instant download of all session logs and daily metrics directly from your browser.
- **Interval Management:** Easily remove accidental clicks or test sessions.

### 📊 Insights & Annual Heatmap
- **Daily Goal Progress:** Live visual progress bar toward your customizable daily goal (e.g., 4h, 6h, 8h, 10h).
- **Streak Counter:** Highlights your consecutive streak of hitting your daily goal.
- **Work vs. Break Balance:** Dual-tone meter measuring focus time against break duration.
- **Time of Day Distribution:** Visual breakdown of productivity across Morning, Afternoon, Evening, and Night.
- **GitHub-Style Heatmap:** Full-year 365-day activity matrix with interactive day selection.

### 🔔 Subtle Synthesized Audio Chimes
- Built using the native Web Audio API (zero external sound files needed).
- Gentle upward tap on start, soft release on pause, and celebratory harmonic bell on sprint completion.
- Easily toggleable in Settings.

### ⚙️ Automation & Cloud Sync
- **Smart Auto-Pause & Resume:** Pauses after configurable inactivity (5m, 10m, 15m, 30m) or screen lock, with automatic bypass if media or calls are playing.
- **Midnight Rollover:** Splits late-night work sessions right at midnight so times are accurately logged across days.
- **Google Sheets Backup:** Direct integration via Google Apps Script for automatic cloud backups.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Space` | Start / Pause active timer |
| `R` | Reset current session |
| `1` | Switch to **Timer** tab |
| `2` | Switch to **Insights** tab |
| `3` | Switch to **Log** tab |
| `4` | Switch to **Settings** tab |
| `Alt+T` (or `Cmd+T`) | Open Focus Flow popup anywhere in Chrome |

---

## 🚀 Installation

1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Toggle on **Developer mode** in the top-right corner.
3. Click on **Load unpacked** in the top-left corner.
4. Select this project folder (`FocusFlow`).
5. Pin **Focus Flow** to your Chrome toolbar for instant access!
